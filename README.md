# SoarBnB

Aplicação web inspirada no Airbnb, desenvolvida com foco em front-end moderno, componentização, rotas e consumo de API, simulando um fluxo real de aplicação web.

## Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de consolidar conhecimentos em desenvolvimento front-end utilizando React, criando uma aplicação completa com múltiplas páginas, autenticação de usuários e integração com uma API.

O back-end foi desenvolvido apenas como suporte para as funcionalidades do front-end, não sendo o foco principal do projeto.

## Funcionalidades

- Listagem de acomodações
- Visualização de detalhes de cada acomodação
- Autenticação de usuários
- Navegação entre páginas utilizando React Router
- Consumo de API com Axios
- Layout responsivo utilizando Tailwind CSS

## Tecnologias utilizadas

### Front-end

- React
- Vite
- React Router DOM
- Axios
- Tailwind CSS

### Back-end (suporte)

- Node.js
- Express
- MongoDB
- Supabase (armazenamento de imagens)

## Deploy

O projeto foi publicado utilizando a plataforma **Render**, permitindo simular um ambiente real de produção e compreender o comportamento da aplicação após o deploy.

Link da aplicação:  
https://soarbnb.onrender.com

> Observação: o serviço pode apresentar um pequeno tempo de inicialização após períodos de inatividade, comportamento comum em planos gratuitos.

## Dependência do back-end

Esta aplicação front-end depende de uma API back-end para funcionar corretamente. Sem o back-end em execução, algumas páginas podem exibir apenas a interface básica, sem carregamento de dados.

## Como executar o projeto localmente

### Front-end

````bash
cd front-end
npm install
npm run dev

### Back-end
```bash
cd back-end
npm install
npm run dev

````
